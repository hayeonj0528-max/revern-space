# REVERN SPACE

한옥과 숲을 중심으로 실제 방문객이 함께 걷고 쉬는 웹 3D 웰니스 센터의 첫 버전입니다. 현재 폴더의 `REVERN_SPACE_BUILD_BRIEF.md`를 기준으로 구현했습니다.

## 실행

Node.js 22 이상이 필요합니다. 실제 개발·검증 환경은 Node.js 24.12.0 / npm 11.6.2입니다.

```sh
npm ci
npm run dev
```

- 체험: **http://localhost:5173/**
- 실시간 서버 상태: **http://localhost:2567/api/health**
- WebSocket: 개발 시 같은 출처의 `/ws`를 통해 2567번 서버로 연결됩니다.
- 개발 클라이언트와 실시간 서버가 함께 실행됩니다. 종료는 터미널에서 Ctrl+C입니다.
- 5173 또는 2567이 이미 사용 중이면 기존 REVERN 프로세스를 종료한 다음 실행하세요. 다른 프로젝트의 프로세스는 임의로 종료하지 마세요.

환경 설정이 필요하면 `.env.example`을 `.env`로 복사하고 수정합니다. Vite와 서버 모두 `.env`를 읽습니다. 기본 로컬 실행에는 환경 변수나 외부 계정이 필요하지 않습니다.

## 두 이용자로 확인하기

1. 일반 Chrome 창과 시크릿 창, 또는 서로 다른 브라우저에서 위 주소를 엽니다.
2. 서로 다른 닉네임으로 입장합니다. 접속자 수에 두 실제 세션이 표시됩니다.
3. 한 창에서 걸으면 다른 창의 캐릭터와 이름표가 이동합니다. 상단 접속자 버튼에서도 현재 공간과 행동을 확인할 수 있습니다.
4. 두 창 모두 지도에서 요가 대청으로 이동합니다. 빈 매트 가까이 걸어가면 나타나는 **앉기** 버튼 또는 **E** 키로 참여합니다. 같은 매트에는 한 사람만 앉을 수 있고, 이미 점유된 매트에서는 앉기 안내가 뜨지 않습니다.
5. 스파의 온탕·냉탕 입탕, 양머리·식혜, 사우나의 벤치 찜질·돌 위에 물 붓기, 플로팅의 튜브 이용, 다실의 차 따르기·마시기도 상대에게 보입니다.
6. 한 사람의 시점 전환·클래식 재생·일시정지는 다른 사람에게 영향을 주지 않습니다.
7. 이용 안내에서 **공간에서 나가기**를 누르면 즉시 퇴장합니다. 네트워크가 끊기면 재접속을 시도하고 15초 동안 자리를 보존합니다. 유예가 끝나면 서버가 자리와 캐릭터를 제거합니다.

이 동기화는 실제 Node.js WebSocket 서버가 수행합니다. localStorage나 BroadcastChannel로 방문객을 흉내 내지 않습니다. 방문객이 없으면 공간은 비어 있고, 요가 가이드만 별도의 안내 캐릭터로 남습니다.

## 조작

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 | WASD / 방향키 | 왼쪽 조이스틱 |
| 시선 | 화면 드래그 | 오른쪽 화면 드래그 |
| 시점 전환 | 1인칭·3인칭 버튼 / V | 1인칭·3인칭 버튼 |
| 마우스 고정 | 3D 화면 더블 클릭, Esc로 해제 | 사용하지 않음 |
| 빠른 이동 | 상단 공간 지도 | 상단 지도 아이콘 |
| 입탕·찜질 | 계단 도보 진입 또는 가까운 체험 버튼 / E | 계단 도보 진입 또는 가까운 체험 버튼 |
| 요가 참여·종료 | 빈 매트 가까이에서 앉기 / E, 참여 중 일어나기 / E | 빈 매트 가까이에서 앉기, 참여 중 일어나기 |

방향을 바꾸면 먼저 제자리에서 몸을 돌린 뒤 앞으로 걷고, 카메라도 진행 방향을 따라 돌아갑니다. S나 조이스틱 아래 방향으로 반대편에 갈 때는 시선도 함께 뒤돌아봅니다. 키나 조이스틱을 계속 누르면 같은 진행 방향을 유지합니다. 팔과 다리는 서로 반대로 움직이고 발걸음은 이동 거리에 맞춰 이어집니다. 드래그로 직접 둘러볼 수 있으며, 쉬거나 요가하는 중에는 카메라가 몸 방향을 바꾸지 않습니다.

모든 공간의 기본 조작부는 오른쪽 아래에 작게 표시합니다. 자리 번호는 **자리 선택**, 차 종류는 **차 선택**, 스파의 수건·식혜·휴식 좌석은 **휴식 도구**를 눌러 펼칩니다. 선택하거나 바깥을 누르면 메뉴가 닫히고, Esc로도 닫을 수 있습니다. 플로팅의 긴 안내와 음악 출처는 **휴식 안내**에서 확인하며, 음악 재생·종료와 내려오기는 펼치지 않고 사용할 수 있습니다.

버튼 조작 후에도 V 키를 사용할 수 있습니다. 이동 키가 동작하지 않으면 입력란이나 버튼에서 벗어나 3D 화면을 한 번 클릭하세요. 지도·설정 대화상자가 열려 있는 동안에는 걷기를 멈춥니다. 대화상자는 Tab·Shift+Tab·Esc를 지원합니다.

## 구현된 체험

- **입구·중정:** 한옥 대문, 석재 길, 작은 수공간과 다리, 입체적인 숲, 바람에 움직이는 잎, 지도 이동.
- **요가 대청:** 12개 매트, 별도 요가 가이드, 서버 공통 시각을 따르는 **8자세 / 32초 루틴**. 약 4초마다 앉아 호흡·팔 올리기·좌우 옆구리 늘이기·좌우 전사 자세·나무 자세·앞으로 접기가 이어집니다. 빈 매트의 중심에서 2.3m 이내에 접근해야 앉기 안내가 나타나고 서버도 거리를 확인합니다. 몸은 모든 자리에서 매트와 나란히 정면을 향하며, 시점을 바꾸거나 드래그해도 유지됩니다. 참여 중에는 작은 동작 표시와 일어나기 버튼만 남기며, 카메라는 가이드가 보이도록 별도로 맞춥니다. 일어나면 매트 옆에 머뭅니다. 실제 신체 동작을 측정하지 않습니다.
- **스파:** 분리된 온탕·냉탕, 각각의 계단과 손잡이, 내부 휴식 라운지 6개 좌석, 양머리 수건·식혜. 계단으로 걸어 들어가면 몸과 1·3인칭 시야가 물 깊이에 맞게 내려가고, 물속에서도 이동할 수 있습니다. 탕 가장자리 가까이에서는 입탕 버튼·E도 제공하며, **탕에서 나오기** 또는 계단으로 나올 수 있습니다.
- **핀란드 사우나:** 스파 오른쪽 문으로 이어지는 별도 목재 공간, 단 벤치·6개 이용 좌석·돌 히터·물통·국자·벤치 아래 조명. 빈 벤치 가까이에서 **앉아 찜질하기 / E**, 이용 중 **찜질 끝내기 / E**. 히터 옆의 **물 한 국자 붓기 / E**는 국자 동작과 공유 증기 효과를 시작하며 서버에서 거리·재사용 시간을 확인합니다.
- **플로팅 홀:** 8개 침대형 튜브, 눕기·내려오기, 불빛과 수면. 고화질에서는 실제 장면의 평면 반사를 512px / 최대 12.5Hz로 갱신하고, 기본 화면은 독립적으로 렌더링합니다. 저화질에서는 가벼운 수면 셰이더를 사용합니다.
- **개인 휴식:** 10분 / 5단계 안내 글, 클래식 음악 시작·일시정지·종료, 시점 전환 중 자리 유지. 재접속 중에는 안전하게 일시정지합니다. 개인 생애 내용은 입력·전송·저장하지 않습니다.
- **다실:** 6개 좌석, 차 선택, 따르기·마시기 동작, 잔의 김과 물 따르는 효과음. 조작 패널은 오른쪽 반투명 패널로 표시하며, 따르기·마시기 중에는 동작 표시와 일어나기 버튼만 작게 남깁니다. 동작이 끝나면 조작이 다시 나타납니다. 3인칭에서는 찻상과 캐릭터를 패널 왼쪽으로 배치해 시야를 확보합니다.
- **설정:** 전체 음소거·음량·환경음과 음악·휴식 안내 글·움직임 줄이기·고화질. WebGL 미지원과 컨텍스트 손실 시 안내 화면.

## 사운드와 교체 가능한 자산

입장할 때 나레이션은 재생하지 않습니다. 플로팅에서도 음성 합성이나 모성적인 나레이션을 사용하지 않습니다. 휴식 안내 글은 설정에서 끌 수 있습니다.

스파·핀란드 사우나에는 입장 후 에릭 사티의 **짐노페디 1번**(피아노 연주: Kevin MacLeod)이 자동으로 시작됩니다. 두 공간 사이를 걸어 이동해도 음악은 이어지고, 구역을 나가면 멈춥니다. 다실에는 클로드 드뷔시의 **아라베스크 1번**(피아노 연주: Patrizia Prati, `arabesque-no1.ogg`)이 흐릅니다. 재생은 개인별이며 전체 음소거·음량 설정이 적용됩니다.

플로팅의 빈 튜브에 누운 뒤 **클래식 듣기**를 누르면 같은 **짐노페디 1번**이 흐릅니다. 음원 파일은 `public/audio/music/gymnopedie-no1.mp3`에 포함되어 있으며 외부 스트리밍 계정이 필요하지 않습니다. CC BY 3.0 녹음으로 출처·연주자·라이선스는 체험 화면과 `public/audio/music/ATTRIBUTION.md`에 표시했습니다.

음악은 개인별로 재생됩니다. **일시정지**와 **음악 이어듣기**는 현재 음악 위치를 유지하고, **음악 종료**·**내려오기**·다른 공간 이동 시 정지 및 초기화합니다. 10분 휴식 동안 곡을 반복합니다. 음소거·음량·**환경음과 음악** 설정은 실제 출력에 적용됩니다. 연결이 끊기면 자동 일시정지하고 사용자가 다시 시작할 수 있습니다.

바람·물·따르기 효과는 WebAudio로 합성합니다. 다른 공간의 환경음을 녹음 파일로 교체할 때는 `public/audio/manifest.json`의 `ambience`에 경로를 지정합니다.

```json
{
  "ambience": {
    "courtyard": "/audio/ambience/garden.mp3"
  }
}
```

위 `garden.mp3`는 교체 예시이며 현재 포함하지 않았습니다. 기본 manifest는 빈 객체이므로 없는 환경음 파일을 요청하지 않습니다. 클래식 음악을 바꾸려면 `client/music.ts`의 경로·곡명·연주자·라이선스와 해당 실제 음원을 함께 변경하세요. 자산의 출처와 사용 조건은 [ASSET_SOURCES.md](ASSET_SOURCES.md)를 확인하세요.

## 구조와 선택 이유

```text
client/     React 화면, 3D 건축·캐릭터·카메라, 개인 사운드
server/     단일 방, WebSocket 연결, 이동·입탕·증기 검증, 자리 점유·정리
shared/     메시지 타입, 구역·자리·충돌체, 명상 대본
public/     클래식 음원·출처, 교체 가능한 환경음 manifest와 정적 자산
tests/      서버 규칙 / 실제 두 Chrome 프로세스 / 모바일 검증
scripts/    클라이언트와 서버를 함께 실행
```

React 19.3.1 + React Three Fiber 9.8.2 + Three.js 0.180.0 + Vite 7.3.7 + TypeScript 5.9.3을 사용합니다. 설치된 실제 버전은 `package-lock.json`으로 고정됩니다.

브리프의 Colyseus는 기술 제안이므로, 이번 단일 메모리 방의 첫 버전에는 `ws` 8.22.1과 명시적인 방 규칙을 선택했습니다. 별도 상태 스키마 런타임 없이 입력·점유·재접속을 직접 검증하기 위한 선택입니다. 서버 30Hz, 상태 배포 15Hz, 클라이언트 입력 최대 약 20Hz입니다. 이동은 좌표가 아닌 방향 요청을 보내고 서버가 속도와 충돌을 적용합니다. 상대 캐릭터는 보간합니다.

서버는 위치·구역·행동·외형·수건·자리·요가 시작 시각을 공유합니다. 재접속 토큰은 해당 연결에만 보내고 공유 스냅샷에는 넣지 않습니다. 시점·명상 진행·음량은 클라이언트에만 둡니다. 세션은 메모리 상태라 서버를 재시작하면 초기화됩니다. 개발 모드의 `window.__REVERN__.getState()`는 읽기 전용 확인용이며 프로덕션 빌드에는 제공하지 않습니다.

## 검증

서버 규칙·빌드·독립적인 E2E 검증:

```sh
npm test
npm run build
npm run test:e2e
```

브라우저 테스트는 macOS의 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`을 기본으로 사용합니다. 다른 환경에서는 `CHROME_PATH`를 지정하거나 `playwright.config.ts`를 조정하세요. 실제 두 Chrome 프로세스의 별도 컨텍스트를 사용하며, 모든 검증이 끝나면 테스트 브라우저를 닫습니다.

E2E는 5174/2568 포트에 검증 전용 클라이언트·서버를 자동으로 열고 완료 후 닫습니다. 평소 사용하는 5173/2567의 방문객과 점유에 영향을 주지 않습니다. 이 두 검증용 포트를 비워두세요.

`TEST_BASE_URL`을 지정하면 자동 서버 시작을 생략합니다. 이 경우 다른 이용자가 없는 별도 개발 서버를 지정해야 합니다. E2E는 상태 확인용 개발 진단 API를 쓰므로 프로덕션 주소에서는 실행하지 않습니다. 프로덕션 배포에서 진단 API를 활성화하지 마세요.

결과는 `playwright-report/index.html`, 화면은 `test-results/screenshots/`에 생성됩니다. 실제 수행 범위·남은 작업은 [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md)에 정리했습니다.

## 프로덕션 실행과 외부 접속

```sh
npm run build
npm start
```

빌드한 앱과 WebSocket을 **http://localhost:2567/** 한 주소에서 제공합니다. 이 방식으로는 정적 서버를 따로 실행할 필요가 없습니다.

같은 공유기에 연결된 다른 기기는 Vite가 터미널에 출력하는 `Network` 주소로 접속할 수 있습니다. 방화벽·무선망 격리 설정에 따라 접속이 제한될 수 있으며, 이번 검증은 같은 Mac의 두 브라우저 기준입니다.

**외부 배포:** 실시간 WebSocket 서버가 필요합니다. 권장 구성은 Render 등 Node 호스트 한 곳에서 `npm run build` 후 `npm start`입니다. Vercel만으로는 멀티플레이어가 동작하지 않습니다. Root Directory·Build/Start Command·환경 변수는 [DEPLOYMENT.md](DEPLOYMENT.md)를 확인하세요.
